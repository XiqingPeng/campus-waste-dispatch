# 智能垃圾监控

适用于 **Windows 10/11，64 位 Intel 或 AMD，普通 USB UVC 摄像头**。一台摄像头监测一个完成标定的垃圾桶。浏览器管理页在本机运行。

## 现在没有摄像头

1. 将 ZIP **全部解压**到有写权限的固定目录，例如 `C:\SmartWaste`。
2. 双击 `INSTALL_WINDOWS.bat`。ZIP 已包含 Windows x64 Python 3.11、锁定的依赖和手部模型。安装在解压目录内完成，核心模式无需联网、自行安装 Python 或插入摄像头。结束时会打印 `Installation complete`。
3. 双击 `DEMO_NO_CAMERA.bat`。浏览器打开本机页面，画面标为「测试模式」。会循环播放一段合成场景，按真实程序逻辑写入测试抓拍和满载记录。满载后可点击「登记已清理，开始复核」，等画面恢复空桶时查看复位。
4. 有自己的录像时，把视频拖到 `REPLAY_VIDEO.bat` 上。录像回放运行实际 MediaPipe 手部模型。用暂停、继续和从头回放来采集参考图。首次回放一段新录像也要标定，参考图可从录像的不同时间点采集。

演示使用合成画面与模拟手部坐标，适合检查界面、状态和保存链路。演示每 1 秒取样，实机默认每 5 秒取样。你的录像可能没有包含连续的投放、满载和清空场景。现场测试应使用固定机位录下这些阶段。

## 插上摄像头后

1. 把摄像头固定在垃圾桶斜上方，确保同一画面能看到投放者上半身和手、桶口及桶内参考区域。
2. 双击 `START_WINDOWS.bat`。此程序也可以在插线前启动。设备断开后，程序会继续在后台尝试重连。自动模式记住上次成功连接的设备编号。如果电脑先选中了内置摄像头，改选「设备 1」或其他编号，并查看实际画面。
3. 展开「摄像头与垃圾桶标定」，填写桶号。分别选择 **桶口**、**桶内**、**满载参考带**，在左侧画面上用鼠标逐点勾出多边形。满载参考带画在桶内接近桶口、能观察到垃圾堆积的位置。
4. 保持摄像头位置和灯光一致，先采集空桶参考图，再采集接近满载图，点击「保存标定」。参考落差过小会被拒绝。
5. 正常投放一次，去「投放记录」放大主图和备用图。确认人物与垃圾同框后，可手动标注类别。需要排查保存时，可用「手动测试抓拍」，记录会标注手动测试。
6. 测试满载后查看「满载记录」。处理完成时，在同一个本机管理页登记已清理。系统继续取样，连贯地看到清空后恢复正常。

装好依赖并完成首次标定后，同一摄像头按原位置、设备编号、后端和画面分辨率重新连接时会自动复用已保存的标定。Windows 可能在更换 USB 插口或设备后改变编号。若画面构图改变，重新标定。开启监控后请保留终端窗口。退出时在终端按 Ctrl+C。

## 两项功能

- **投放抓拍**：MediaPipe 识别手部关键点。手部从桶口外移入、且 OpenCV 检测到桶口 ROI 内有像素变化时，生成疑似事件。在约 3 秒的滚动帧缓存中按时间与清晰度选取主图和备用图。对照片中物品可见性的判断由审核员完成。
- **满载监测**：用标定区域的颜色和纹理，对照空桶、接近满载图。默认每 5 秒判定一次。连续 3 次有效判满才写入确认时间并创建一条后台任务记录。手部遮挡、过暗或偏离参考图时提示「无法判断」。清理登记和连续空桶复核共同控制复位。
- **本机数据**：FastAPI 仅在 `127.0.0.1` 提供页面。SQLite 保存记录与标定，照片保存到本地文件。「满载记录」可以导出时间和任务状态。所有操作都在同一个管理页面内。
- **参数**：`config.json` 可调整采样周期、确认和复位次数、帧差阈值、冷却时间。保存后重新启动程序。满载判定是固定视角下的视觉估计，参数需要根据真实录像调试。

## 换一台电脑运行

把原 ZIP 复制给另一台 Windows 10/11 x64 电脑，全部解压后双击启动脚本。各电脑使用自己的解压目录、运行环境和数据库，首次安装可离线完成。迁移到新电脑时，用 ZIP 重新安装。从旧电脑保留历史时，先退出程序，再复制整个 `data` 目录。换摄像头或机位后重新标定。

## 运行状态与排查

- **一直等待设备**：检查 Windows 的相机隐私设置是否允许桌面应用访问相机，关闭占用该设备的软件，拔插再试。若画面分辨率和以前不同，页面会重新要求标定。
- **满载判不出来**：核对画面能否看到参考带。桶盖、塑料袋和阴影可能挡住视野。采集代表性的参考图，或降低俯角后重新标定。
- **安装失败**：请检查 ZIP 是否全部解压、文件夹是否可写、是否为 Windows x64，以及磁盘是否有约 1 GB 的可用空间。OpenCV 在 Windows 上导入失败且提示 DLL 时，请核对 Microsoft Visual C++ x64 运行库，Windows N 版还需检查 Media Feature Pack。见 [OpenCV PyPI FAQ](https://pypi.org/project/opencv-contrib-python/)。
- **记录位置**：`data/live` 保存真实相机记录，`data/demo` 与 `data/replay` 保存测试记录。每个目录都有数据库和运行日志。备份时先退出程序，再复制相应的整个目录。
- **浏览器未打开**：用浏览器打开终端输出的地址，通常实时监控为 `http://127.0.0.1:8765`。端口被占用时会选择临近端口。启动程序时保持 ZIP 解压后的目录结构。

实体摄像头检测效果需现场试拍。首先比较实际投放和路过、伸手、开盖等对照情形，再验证空桶、持续满载、遮挡和清理过程。样本数和判断结果应以真实录像和日志为准。

软件和离线包的验证范围见 `VALIDATION.md`。已安装后可在项目目录运行 `.venv\Scripts\python.exe -m unittest discover -s tests -v`。
