# 验证结果与范围

| 检查 | 结果 |
| --- | --- |
| 无摄像头演示 | 在测试环境启动 FastAPI，浏览器显示实时测试画面、抓拍主图与备用图、满载确认时间。通过页面登记清理后检查到复位记录。 |
| 投放双信号 | 自动测试验证单有手部轨迹或单有桶口变化都不会记录投放。合成场景组合两类信号后写入三张 JPEG。 |
| 满载与清理 | 自动测试覆盖连续有效采样、遮挡中断、重复采样、数据库重启后仍只保留一张任务，以及清理后连续复核。 |
| 数据完整性 | 自动测试覆盖标定检查、照片读取、人工审核、CSV 导出和本机页面的请求令牌。 |
| 原 PPT 两段录像 | OpenCV 逐段解码，MediaPipe 在抽样帧中返回手部关键点。这些录像是概念演示，适合检查解码和模型运行。 |
| 断线重连 | 用模拟摄像头接口测试等待设备、接入、拔出与再接入。 |
| 便携安装包 | 包含已核对校验值的 Windows x64 CPython 3.11、目标平台依赖和手部模型。安装脚本使用 ZIP 内轮子，软件启动不依赖开发机器的路径。 |

测试环境没有 Windows 实机和实体摄像头。Windows 安装脚本及机型兼容性、真实监控捕捉率和满载识别准确率需要用实际电脑与摄像头完成现场验证。初次使用建议先检查相机视野，然后做真实投放、路过、开盖、遮挡、满载与清空的对照测试。
