# 校园清运点位

当前启用 20 个模拟站点，每站四类垃圾桶（recycle 可回收物、food 厨余垃圾、residual 其他垃圾、hazard 有害垃圾），共 80 个桶。地图只画站点，四类设备在站点详情、站点/类型筛选和模拟器中展示。

`collection-points.json` 保留原 50 个位置的元数据，`active: true` 的 20 个进入当前目录，其他 30 个仅用于旧记录查阅。`station_code` 是界面展示编号，按分区顺序连续编号 GZ-001～GZ-020；`station_id` 是内部稳定标识，用于关联已有设备和工单。界面桶号统一为 `<station_code>-<category>`，API 写入仍传原始桶 ID。原 residual 桶继续使用站点编号作为桶 ID，另三类使用 `<station_id>-<category>`，避免覆盖原桶和工单历史。名称、分区和坐标参考用户提供的单文件 Demo，`source_id` 保留原始编号。
