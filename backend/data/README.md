# 校园清运点位

50 个模拟点位，编号按修改保洁界面.md 的附录统一为 GZ-001～GZ-050。名称、分区和归一化地图坐标参考用户提供的保洁调度Demo-单文件版.html；source_id 保留其原始编号供核对。

每个点位只代表一个普通生活垃圾桶。坐标为 1400×950 地图上的相对位置，不能作为实际路网距离。地图几何来自参考文件标注的 OpenStreetMap 数据（© OpenStreetMap contributors，ODbL https://www.openstreetmap.org/copyright），布局参考 HKUST(GZ) Campus Map。本项目将配色调整为现有绿/米色风格。

点位没有接入真实设备；初始状态为 unknown，不生成虚假的在线心跳。

体育区根据校方 Campus Map（https://studyathkustgz.hkust-gz.edu.cn/detail-819 ，地图图片 https://studyathkustgz.hkust-gz.edu.cn/uploadfile/2025/05/07/15-01-40/image.jpeg）重绘体育馆、东侧弧形景观广场、北侧水景与连接道路，并以教学楼/行政楼地标将官方图示对齐到现有示意坐标系。同步校正 GZ-041～GZ-044 的四个演示位置；不表示测绘或实地部署坐标。未复制官方地图图片，草地不含装饰点。
